# origin-setter
A Blender addon to set origin of an object to selected geometry with a single shortcut (Ctrl-W)
(must be in edit mode)

Works on all meshes and curves.

Saves you the hassle of select geometry -> shift S -> 3D cursor to geometry -> Tab -> object -> set origin to 3D cursor.


https://github.com/user-attachments/assets/c0376b0e-7dff-4d2f-a860-7a2c23ffdd2e



Shortcut is changeable under Edit > Preferences > Keymap > 3D View > 3D View(Global) > Set Origin
